# HoursGram Desktop

This folder is the native Windows client source. It is based on AyuGram Desktop 7.0.9 and Telegram Desktop, so the interface is implemented with the native C++/Qt desktop UI rather than the web client in a Tauri window.

The executable target is named `HoursGram.exe`. Its app ID and Windows profile folder use HoursGram names, keeping its settings and account data separate from Telegram Desktop and AyuGram.

The upstream `LICENSE` and copyright notices remain in this source tree. AyuGram and Telegram Desktop are credited in the About window and source links.

The existing TypeScript web client remains in the parent folder.
